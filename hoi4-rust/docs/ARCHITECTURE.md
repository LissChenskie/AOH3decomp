# Архитектура «Iron Front» — HOI4 на Android, Rust, графика в стиле AoH3

## Принципы
1. **Симуляция ≠ рендер.** Ядро (`sim`) — чистый Rust, без GPU/IO-зависимостей, работает headless (тесты, сервер авторасчёта). Рендер читает только immutable-снимки состояния.
2. **Данные ≠ код.** Все определения (страны, штаты, технологии, фокусы, события, оборудование) — во внешних файлах формата HOI4-подобного DSL (парсим через `jomini`). Код ядра не знает названий стран.
3. **Компактность.** u16-идентификаторы провинций/стран, SoA-хранилища, сохранения — бинарный дельта-формат с версией схемы.

## Ключевые подсистемы

### Карта (стиль AoH3)
- Источник: PNG-маска HOI4 (каждой провинции — уникальный RGB) → офлайн-генератор строит: растер индексов u16, список полигонов (RDP-упрощение), adjacency-граф, центры масс.
- Рендер: один fullscreen-pass рисует индексный тайл-атлас; цвет = f(владелец|местность|mapmode) через lookup-текстуру; границы — предзаписанный слой; выделение — outline-полигон. 60 FPS на среднем телефоне за счёт отсутствия per-province draw call'ов.

### Время
- HOI4-календарь: день/неделя/месяц; speed 1..5 (1 день = 1с … 5 дней = 1с). Тик симуляции фиксированный: `HourTick` (24/сутки) для боёвки/маршей, `DailyTick` для экономики/политики/производства, `WeeklyTick` для опыта/рекрутов/сопротивления, `MonthlyTick` для снабжения-рейтинга/стабильности. Порядок систем зафиксирован и протестирован — детерминизм.

### Модификаторы
Единый механизм `ModifierMap<f32>` (как в HOI4): источники (духи, доктрины, лидер, местность, погода…) складываются мультипликативно/аддитивно согласно вики-спецификациям каждой формулы. Каждая формула — чистая функция с юнит-тестом против эталонных чисел из combat-логов/расчётов вики.

### Симуляция (ECS-lite, SoA)
`Divisions`, `States`, `Countries`, `Armies`, `Navies`, `AirWings`, `Convoys`, `Fronts`, `Wars`, `FocusTrees`, `ResearchQueues`, `ProductionLines`. Системы обрабатывают только dirty-множества (пересчёт затронутых провинций, а не всей карты).

### Сохранения
Бинарный формат: заголовок(version, hash данных) + секции по мирам + dictionary-интернинг строк. Target: < 3 МБ на 1936+сценарий. Roundtrip-тесты в CI.

### ИИ
Уровневая архитектура (по образцу описаний Expert-AI/открытых модов): стратегический план (театры, цели-штаты) → операционный (дивизионные пулы, наступательные окна, supply-ограничения) → тактический (фронты, резервы). Эвристики сверяются с поведением vanilla-AI по реплеям/логам.

### Android
- `android-activity` + `winit` + `wgpu` (Vulkan/GLES fallback), `egui` для HUD.
- Ограничение памяти: ленивая распаковка ассетов (zstd), кэш текстур ≤ 96 МБ, single-threaded sim + render thread.
- CI: GitHub Actions — linux-headless build+tests; nightly cross-compile aab.
