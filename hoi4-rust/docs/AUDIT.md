# Аудит исходных репозиториев (2026-10-23)

## 1. CTD-Games/AnalyticalEngine

| Параметр | Значение |
|---|---|
| Что это | Открытая рекомпиляция **десктопной** Age of Civilizations 3 («AOC3, Open Sourced», Project Orion) |
| Язык | Java (JDK 23), скрипты — NashornJS |
| Лицензия | **MIT** (Copyright 2025 Confoederatio) ✅ разрешает использование/модификацию |
| Размер репо | ~1.4 ГБ (клон не влезал в песочницу; анализ шёл через GitHub API) |
| Реального кода | 65 .java файлов (~20–30 тыс. строк). Остальное — бандл JDK, .class, ассеты, dll/so |
| Статус | Beta; кастомные mapmodes/event effects частично; MP в тестировании |

**Ключевые модули:** `Framework` (Window/LWJGL-рендер, Javascript-скриптинг), `Java/GameThreads` (игровой тик), `OnActions` (War, WarManager, SiegeManager, Province, Diplomacy, ArmyRecruit), `MapEditor`, `ScenarioEditor`, `menusInGame`, легаси-классы `aoc.kingdoms.lukasz.*`.

**Вывод:** это движок AOC3 (= упрощённый AoH), а **не** HOI4. Механик HOI4 (фокусы, дивизии, снабжение, боёвка по формулам HOI4) там нет вообще. Как «основа движка» для Rust-проекта он непригоден напрямую: Java→Rust портирования не существует; ценность = справочник по 2D-карточному рендеру, структуре сценариев, формату данных AOH-семейства и как образец лицензии MIT.

| Состав | java-game/ (~1500 классов jadx), smali/ (8276 классов), AndroidManifest.xml |

| Лицензия | ❗ Проприетарный код Lukasz Jakowski. Использовать как **референс архитектуры**, копировать код в публичный проект нельзя |

**Ценность для нас:** эталон того, как устроена 2D-провинциальная стратегия на Android: загрузка карты из bitmap-маски + JSON, слои провинций/границ, тик симуляции вне UI-потока, компактные сохранения.

## 3. Форматы HOI4 (для парсера)

- Данные HOI4 — CLAUSETXT-подобный DSL (`key = value`, блоки `{}`, комментарии `#`). Парсер: ориентир — **rakaly/jomini** (MIT, Rust) — готовый ридер+писатель этих форматов.
- Карта: провинции в bitmap-маске (PNG) + `province_definitions.csv` + geometry-файлы (`defines/*.dat`), штаты в `history/states/`. Инструменты: ScottyThePilot/hoi4_province_editor (Python), raederhans/scenario-forge.
- Логи боёвки имеют стабильный формат → эталонные тесты формул можно сверять по combat-логам.

## 4. Правовая рамка проекта

1. Механики/формулы HOI4 — не охраняются авторским правом (идеи), но **данные HOI4** (карта, фокусы, тексты, иконки, названия) — собственность Paradox. Для фан-проекта: данные собираются из открытых источников/пересоздаются; релиз только как мод/датипак, не самостоятельная продажа.
2. Наш код — MIT (совместимо с jomini, wgpu, egui).
3. Код AOH3/AnalyticalEngine — только как референс; в наш репозиторий не копируем (кроме MIT-кода AE, если что-то понадобится, с сохранением copyright).

## 5. Технические риски

| Риск | Митигация |
|---|---|
| Полная карта HOI4 (~5600 провинций) тяжела для телефона | тайловая/уровневый LOD рендер, precomputed полигоны, delta-цвет слоёв |
| Тяжёлая симуляция (производство, ИИ) при паузе-ориентированном геймплее AOХ-стиля | tick-based ECS, инкрементальные пересчёты, профилирование на реальном устройстве |
| Объём контента HOI4 (тысячи фокусов/технологий) | внешний data-pak, генераторы из открытых дат-файлов, заглушки ресурсов |
| Нет доступа к байткоду HOI4 (Paradox EULA запрещает реверс) | формулы восстанавливаем по официальной вики, combat-логам, открытым модам и симуляторам (taw/hoi4) |
| Сборка под Android в песочнице отсутствует (нет NDK/SDK) | CI на GitHub Actions (rust-on-target + cargo-ndk + gradle); локально — headless-симуляция и юнит-тесты |
